# Gallery — proof the machine works

Before/after from the violin build (fictional private-sale page for the 1716
"Messiah" Stradivarius), the run that stress-tested the notslop machine.

## What you're seeing

**v4-baseline-1440.png** — the earlier build. Same brief, same thesis
("this object is evidence, not merchandise"), but the exhibits are SVG
line drawings of a violin: clean, correct, and completely unconvincing.
An illustration standing where a photograph should be. This is what the
machine's standing law now forbids — *real product photography outranks
illustration, always* — and the reason the imagery gate blocks a build
rather than letting the builder draw the product.

**v5-final-1440.png / v5-final-375.png** — the same page after the full
machine: frozen brief → direction → quarantined build → renders → critic →
8 passes → human verdict. Three photographic plates in a documented register
(dead-center, upright, captioned like evidence), a pressed seal, a registrar's
hand, redacted access lines, a cancellation stamp — every material mark naming
a past event, per the handling-vs-decoration test. Desktop and mobile.

The difference between the two images is the whole project: v4 executes the
thesis thinly; v5 commits to it. The machine exists to make v5 the repeatable
outcome instead of the lucky one.
