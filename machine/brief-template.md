# BRIEF TEMPLATE — the machine's direction
**notslop machine · Part 1 of 6**

The brief is not inspiration. It is a constraint document that makes the generic
answer unreachable *before any code exists*. If the generic answer is still
reachable after the brief, the brief failed — rewrite it, never the build.

## The 5 fields (minimum sufficient, 100–150 words total)

Brevity is the forcing function. If you need more than ~150 words, you have not
chosen — you are hedging.

**S0 SCOPE (declared with the brief, outside the word count):** page count and
one-line purpose per page. Default: single page. The site-architect builds
exactly this sitemap — no more pages, no fewer. A multi-page scope must justify
itself: each additional page needs a purpose the primary page cannot serve.

| # | Field | What it must contain |
|---|---|---|
| F1 | **PROBLEM** | The actual job this artifact does, in one sentence. Not the topic — the job. |
| F2 | **AUDIENCE** | One sentence with a non-obvious truth about the reader/viewer. If swapping in the default audience leaves the solution unchanged, this field failed. |
| F3 | **THE ONE IDEA** | The single positive thesis the artifact must express. This is the R4 positive-thesis requirement: every build must be *for* something, not merely *against* genericism. {{AMMO: brief.md steal/leave pattern examples for visual projects}} |
| F4 | **NOT-LIST** | Named prohibitions. Each must name a specific generic default ("not another gradient hero with centered headline and three feature cards"), never a vague vice ("not boring"). Minimum 3. Incorporate the standing Refuse list (stolen from impeccable): {{AMMO: project-independent kicker bans — no brief earns them back}} |
| F5 | **FEEL→DO** | The emotional state on arrival and the single action it must cause. The final fitness check at ship: did the artifact produce the DO? |

## The 3 unreachability tests (adversarial brief check)

The draft must pass all three before freezing. The critic verifies them as P0
findings when they fail.

1. **Audience Flip.** Swap in the category's default audience. If the same solution
   still works, F2 failed — the audience is decoration.
2. **Not-List Sweep.** Name the 3 most common category-default examples explicitly.
   Every one must be killed by a specific NOT-list item. If any survives, F4 failed.
3. **Adjective Negation.** Every tone adjective's "is not" must forbid a real,
   tempting decision. "Elegant, not _" — if the negation forbids nothing you'd
   actually do, the adjective is shelfware.

## Freeze

The frozen brief becomes **ledger entry #1** and the boss of everything downstream.
The critic judges the artifact against the frozen brief — never against the
builder's retelling of it. (Stare decisis applies to the brief too: APPLY /
DISTINGUISH / OVERRULE, OVERRULE requires a re-brief, not a fix.)

## Research-before-writing (mandatory)

The brief-writer may not invent insights from priors. Before drafting:
(a) inventory the category's 3 generic defaults by name (these feed the Not-List
Sweep); (b) gather audience evidence (usage data, analogous cases, competitor
behavior). Log artifacts alongside the brief. A brief whose insight is a platitude
hasn't done the work.

## Worked example — the violin page

*Context: fictional private-sale page for the 1716 "Messiah" Stradivarius,
$20,000,000 asking price, with a footer disclaimer that the real instrument
belongs to the Ashmolean Museum and is not for sale.*

- **PROBLEM:** Convince a qualified buyer that this is a once-in-a-century
  acquisition worth engaging a private broker over — the page is a door, not a
  catalog.
- **AUDIENCE:** Ultra-high-net-worth collectors who have seen every "rare
  instrument" pitch and are bored by provenance theater; they respond to
  specificity (measurements, custody records) and are repelled by adjectives.
- **THE ONE IDEA:** *This object is evidence, not merchandise* — the page should
  read like a dossier compiled by someone who doesn't need to sell.
- **NOT-LIST:**
  1. Not a luxury-goods page (no cream, no serif-on-cream, no gold accents).
  2. Not a tech-startup page (no gradient hero, no dual CTA, no feature grid).
  3. Not an auction-house pastiche (no gavel imagery, no "bid now" urgency).
  4. Standing refuses: no eyebrow-above-heading kicker; no monospace-as-technical-costume.
- **FEEL→DO:** Feel: quiet authority, the calm of a sealed archive. Do: request
  the private dossier (single contact path, no form-grid).

*Unreachability check:* Audience Flip — a generic "rare violin for sale" page would
work for any wealthy browser; this brief's specificity (custody records, no selling)
fails for the default audience. Not-List Sweep — the three category defaults
(luxury pastiche, startup landing, auction theater) are each killed by name.
Adjective Negation — "quiet authority, not *provenance theater*" forbids the
adjective-stuffed copy the category defaults to.
