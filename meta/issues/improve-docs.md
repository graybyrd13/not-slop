# Improve the docs

**Good first issue — close a documentation gap**

## Background

The repo's docs are its interface: `README.md` for visitors, `SKILL.md` for
agents that will run the machine, `CONTRIBUTING.md` for proposers, and the
`performance/` knowledge base for auditors. First-time readers trip over the
same things — and the best person to spot a gap is someone seeing the docs
fresh. Find one place where the docs are wrong, missing, or confusing, and
fix that one thing. Small, verifiable, one PR.

## Definition of done

- [ ] The PR changes exactly one doc file (`README.md`, `SKILL.md`,
      `CONTRIBUTING.md`, `gallery/README.md`, or one file under
      `performance/`) and fixes one named gap — no drive-by rewrites, no
      invented content, no speculative claims about the machine.
- [ ] Every claim in the changed text is checkable against the repo itself
      (paths, commands, entry formats, file names all match what's really
      there).
- [ ] The change passes a cold-read test: a contributor with no prior
      contact with the project can follow the affected section end to end
      without guessing.
- [ ] The PR body states the gap you found in one sentence and why the fix
      is correct.
