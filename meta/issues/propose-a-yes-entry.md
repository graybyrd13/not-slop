# Propose a YES entry

**Good first issue — add an exemplary site to the bar**

## Background

`corpora/YES_CORPUS.md` is the machine's bar: exemplary sites, each with one
nameable, abstractable excellence claim — an idea, not a look. The test: if
you can state what makes it excellent without describing how it looks, it's
an entry. If the excellence evaporates without the screenshots, it's surface.
Find a site that shows what winning looks like and name what the machine
should steal from it. See the evidence bar in `CONTRIBUTING.md` and the
`new-yes.yml` issue template.

## Definition of done

- [ ] The entry is appended to `corpora/YES_CORPUS.md` in the exact format:
      `<n>. **<Site> (<url>)** — <genre>. <Excellence claim: the idea,
      abstractable.>` plus a line on what it teaches / why it works for a
      builder.
- [ ] The entry names the site, its genre, and its URL.
- [ ] The excellence claim is stated as one abstractable sentence — the idea
      a builder could apply to a completely different brief.
- [ ] It passes the surface test: the claim survives with the screenshots
      removed (no "it's just beautiful").
- [ ] You searched the existing corpus first; the site isn't already listed.
