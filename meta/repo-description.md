# GitHub "About" description

A machine that makes AI-built websites read as professionally made. not-slop is
a multi-agent pipeline — frozen brief, direction tournament, quarantined build,
rendered criticism, eight ordered passes, and a human verdict — backed by
evidence-graded corpora of AI tells to forbid (the NOS corpus), exemplary
sites to learn from (the YES corpus), and a library of concrete techniques
with stated failure modes. Give the skill to any AI agent; everything in the
corpora grows by proposal, and every proposal lives or dies on data.
